      Know what happens before you upload.

      Selfie search compares a reference photo with faces in the selected event collection. Matches can be imperfect. Review the results before downloading.

      What helps

      • A clear, well-lit selfie with one face
      • Event photos where faces are in focus
      • Waiting until the event shows as ready

      What can affect results

      • Distance and motion
      • Face coverings, sunglasses, and hats
      • Unusual angles and dim rooms

      A match suggests a resemblance. It isn’t proof of identity, and it isn’t a way to control who can see a photo.

      Questions

      Answers marked as preview notes depend on launch decisions that aren’t final yet.

      Who is FindPhotosOfMe for?

      Conference hosts, community organizers, and photographers who want to help attendees find themselves in an event collection.

      How do attendees find their photos?

      They open the event link, sign in, and upload a clear selfie. The service looks for likely matches in that event’s photographs.

      Do attendees pay?

      The planned model keeps attendee search free. The organizer pays for the event collection.

      Do attendees need an app?

      They can use the event’s web page in a browser. The original version also used Telegram; whether it’s available for a given event should be confirmed.

      Will it find every photograph?

      No face-matching system is perfect. Clear faces and good lighting help; distance, motion, face coverings, and unusual angles can affect results.

      How long does processing take?

      It depends on the collection and the service workload. Wait until the event shows as ready before sharing the search link. Preview note: real timing guidance will follow benchmarking.

      Can I use it for a marathon?

      It’s a promising use case to test with a representative photo collection. Sports performance and very large galleries haven’t been validated for the new offering yet.

      What happens to my selfie?

      Preview note: the release must explain storage, processing, and deletion clearly before it collects any selfie. This preview doesn’t publish a storage or deletion schedule.
